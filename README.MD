 StockPilot — Stock Management System

StockPilot is a Python-based Stock Management System developed as a Programming Fundamentals project. It provides basic inventory management functionality, allowing users to manage products, monitor stock quantities, and perform essential stock operations.

The project focuses on applying fundamental Python programming concepts to solve a real-world inventory management problem.

 Features

- Add Products: Add new products to the inventory.
- View Inventory: Display available products and their details.
- Update Products: Modify existing product information.
- Delete Products: Remove products from the inventory.
- Stock Management: Increase or decrease product quantities.
- Search Products: Find products using their names or IDs.
- Low Stock Monitoring: Identify products with limited available quantities.

 Programming Concepts Used

This project demonstrates the practical implementation of fundamental Python concepts:

- Variables and Data Types
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`for` and `while`)
- Functions
- Lists and Dictionaries
- String Manipulation
- User Input and Output
- Basic Input Validation

 Technologies Used
